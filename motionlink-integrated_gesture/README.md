# motionlink
MotionLink — Computer vision and spatial interaction for trajectory visualization and racing-line analysis.

## Run

Windows: double-click `run.bat`. macOS/Linux: `./run.sh`. It installs dependencies, downloads real circuit data on first run, starts the server and opens http://127.0.0.1:5000.

See `docs/integration.md` for how the frontend and backend connect, and `docs/circuits_api.md` for the circuit API.

Circuit data: [TUMFTM racetrack-database](https://github.com/TUMFTM/racetrack-database) (LGPL-3.0). Lap times shown are simulated estimates from a simplified model, not real lap times.
